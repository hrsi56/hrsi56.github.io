# האתר האישי של ירדן ויקטור דג׳ורנו

אתר אישי בעברית, המאגד מחקר, פרויקטים, ניסיון והשכלה.

**האתר:** [hrsi56.github.io](https://hrsi56.github.io/)

## הרצה מקומית

זהו אתר סטטי; אין צורך בהתקנת חבילות או בתהליך build. מתוך תיקיית הריפו:

```sh
python3 -m http.server 4173
```

פתחו את [התצוגה המקומית](http://localhost:4173/). לסיום השרת לחצו `Ctrl+C`.

## עריכת התוכן

- `index.html`: מבנה האתר והתוכן, כותרות, ניסיון, השכלה ופרטי קשר.
- `app.js`: התנהגות הממשק — סינון, ניווט, חלונות פירוט והעתקת דוא״ל.
- `projects.json`: המקור לרשימת הפרויקטים, לתיאורים ולקישורים. אחרי עריכה הריצו `node scripts/render-projects.mjs` כדי לעדכן את הכרטיסים ב־HTML, ואז `node scripts/check-site.mjs`. כך הכרטיסים וחלונות הפירוט מציגים תוכן זהה.
- קובצי העיצוב קובעים את הצבעים, הטיפוגרפיה והתאמת האתר למסכים שונים.
- `assets/`: גופנים, איורים ומסמכים המיועדים לפרסום.

בעת שינוי פרויקט, בדקו שהשם, תיאור התרומה והקישורים תואמים לריפו הציבורי שלו. לפני הוספת מסמך להורדה, ודאו שאינו כולל מספר זהות, כתובת פרטית או פרטי קשר של אחרים שאינם מיועדים לפרסום.

## בדיקות

```sh
node scripts/render-projects.mjs
node scripts/check-site.mjs
```

הסקריפט בודק עברית ו־RTL, קישורים ומשאבים מקומיים, עוגנים, תיאורי תמונות ושמות נגישים לחלונות דיאלוג. הוא אינו מאמת זמינות של אתרים חיצוניים. לאחר שינוי, מומלץ לבדוק גם את הממשק בדפדפן, ברוחב טלפון ובניווט מקלדת.

## פרסום ב־GitHub Pages

בהגדרות הריפו, תחת **Settings → Pages**:

1. בחרו **Deploy from a branch**.
2. בחרו ענף **main** ותיקיית **/ (root)**.
3. שמרו. עדכונים שנדחפים לענף מתפרסמים בכתובת האתר.

אין צורך במפתחות API, בסודות או בשרת יישומים לצורך הפעלת האתר. פניות נשלחות דרך קישור הדוא״ל; אין בסיס נתונים לאיסוף פניות.
